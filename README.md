# Portfólio de Lucas Ribeiro Alves

Bem-vindo ao meu portfólio pessoal! Este projeto exibe minhas habilidades, experiência e projetos como desenvolvedor. Foi construído com HTML, CSS e JavaScript, e está implantado no GitHub Pages para fácil acesso.

## Visão Geral
Este portfólio é uma página web dinâmica e responsiva que carrega meus dados de perfil (nome, profissão, habilidades, etc.) a partir de um arquivo JSON e os exibe com elementos interativos, como acordeões. O design inclui ícones personalizados, fontes e uma imagem de fundo, todos hospedados junto ao código.

## Recursos
- **Conteúdo Dinâmico**: Carrega informações de perfil, habilidades, idiomas, projetos do portfólio e experiência profissional a partir de `data/profile.json`.
- **Design Responsivo**: Otimizado para desktop e dispositivos móveis.
- **Interface Interativa**: Utiliza JavaScript para alternar seções de acordeão e exibir dados.
- **Estilização Personalizada**: Inclui SVGs personalizados, uma fonte única (NeueMachina) e uma imagem de fundo.

## Tecnologias Utilizadas
- **HTML5**: Estrutura da página web.
- **CSS3**: Estilização com ativos personalizados (ícones, fontes, imagens).
- **Google Fonts***: Fontes e ícones.
- **JavaScript**: Gerencia a busca de dados e atualizações no DOM.
- **GitHub Pages**: Hospeda o site ao vivo.
